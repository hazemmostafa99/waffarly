## آخر قرار مؤكد من المستخدم

«نعم، ٢٥٠ لكل المبيعات الجديدة، والمبيعات السابقة تفضل زي ما هي».

هذا يحسم استخدام آخر سعر شراء مؤكّد لكل المبيعات الجديدة بما فيها استهلاك المخزون القديم. لا متوسط تكلفة، ولا إعادة حساب للمبيعات السابقة.

## خط الأساس

- التوسعة الحالية توثيق فقط؛ لم تُعدّل API أو database أو العقود أو واجهات الأسعار بهذه المهمة.
- المشتريات القائمة تحفظ المورد والمستودع والكميات، وتؤكد الاستلام؛ لا أسعار مالية في عقد بند الشراء الحالي.
- وصفات ومتطلبات استهلاك محفوظة وحركات استهلاك/استعادة موجودة في source؛ لا يعتبر وجودها تسليمًا لتكلفة البيع.
- لم تُشغّل اختبارات أو فحوص آلية، ولم تُنفذ معاملات مالية أو migrations. المراجعة الحالية قراءة source وروابط الوثائق.
- مساحة العمل بها تغييرات مستقلة سابقة، بما فيها API وواجهات ووثائق؛ ليست جزءًا من هذه الميزة ولا يجوز نسبتها إلى مراحلها.
- إصلاحات السايدبار وزر إنشاء صنف المخزون السابقة ليست تسليمًا لأي مرحلة من مراحل التسعير والربحية.
